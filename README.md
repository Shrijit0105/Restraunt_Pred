## RESTAURANT PREDICTION

This is a restaurant prediction system uses ai ml techniques to predict the ratings of different enlisted restaurants based on other features like cuisine type,price etc 

This project is a part of my AI/ML portfolio for learning regression techniquees data preprocessing,feature engineering etc.

## Project Overview ##


## Project Objective

Develop a machine learning model capable of predicting restaurant ratings based on available restaurant information.

The project focuses on:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Regression model comparison
- Model evaluation
- Feature importance analysis

## Dataset

The dataset contains restaurant-related information including:

- Restaurant Name
- City
- Locality
- Cuisines
- Average Cost for Two
- Currency
- Price Range
- Online Delivery
- Table Booking
- Votes
- Aggregate Rating
- Rating Color
- Rating Text
- And other restaurant features.

Target Variable:

- Aggregate Rating
